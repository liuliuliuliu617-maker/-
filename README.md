# B站评论智能分类与分析系统

本项目是一套基于 **Qwen2.5**、**Flask** 与 **React** 开发的 B 站评论智能分类与可视化分析系统，支持评论采集、模型分类、用户管理、关键词管理、历史视频查询及评论结果展示等功能。

## 在线访问

项目地址：[http://1.94.247.8/](http://1.94.247.8/)

> **提示：** 项目部署在租用的华为云服务器上。如果网站暂时无法访问，可能是云服务器已经到期或服务暂未启动，建议根据下方说明在本地运行。

## 模型文件说明

由于模型文件体积较大，无法直接作为普通文件上传至 GitHub。本项目使用 **Git LFS（Large File Storage）** 管理大文件。

运行项目前，请先安装并初始化 Git LFS：

```bash
git lfs install
git clone <项目仓库地址>
cd <项目目录>
git lfs pull
```

下载完成后，请检查模型文件是否已经存放到 `.gitattributes` 所配置的对应目录中。

> 如果模型文件并未通过 Git LFS 托管，请根据项目提供的下载地址手动下载，并放入 `models/` 对应的模型文件夹。

## 核心文件说明

### 模型训练

#### `Qwen2.5_train.py`

模型训练脚本，用于读取本地训练数据并对 Qwen2.5 模型进行微调。项目采用参数高效微调方案，可根据不同评论板块训练相应的模型适配器。

#### `训练文本/`

存放模型微调所需的训练数据。运行训练脚本前，请确认数据格式、标签编号及文件目录与脚本中的配置保持一致。

#### `models/`

存放本地 Qwen 基础模型和各板块对应的模型适配器。由于该目录体积较大，需要通过 Git LFS 或项目提供的外部下载地址获取。

### 前端

#### `pinglun/`

前端采用 **React** 和 **React Router** 开发，主要包含以下模块：

- 用户登录与注册；
- 用户中心；
- 视频评论处理；
- 评论分类结果展示；
- 评论概览与词云展示；
- 历史视频及评论记录管理；
- 页面导航与访问路径重定向。

项目采用组件化设计，每项功能由独立组件管理，并配有对应的 CSS 文件，以减少样式冲突并提高代码的可维护性和可扩展性。React Router 用于实现单页应用中的页面切换，`Navigate` 组件用于访问路径重定向。

运行前端前，请先安装 [Node.js](https://nodejs.org/)，然后在前端目录中执行：

```bash
cd pinglun
npm install
npm start
```

前端默认访问地址通常为：[http://localhost:3000](http://localhost:3000)。

> 推荐使用 PyCharm、Visual Studio Code 或其他支持 Python 与 React 的开发工具打开项目。

### 后端

#### `server.py`

Flask 后端服务入口，负责连接前端、模型、爬虫和数据库，主要提供以下接口：

| 接口 | 功能 |
| --- | --- |
| `/api/login` | 用户登录 |
| `/api/register` | 用户注册 |
| `/api/process` | 爬取并分类指定视频的评论 |
| `/api/keywords` | 查询、添加和删除用户关键词 |
| `/api/user/videos` | 查询或删除用户的视频记录 |
| `/api/user/video_comments` | 查询指定视频的评论分类结果 |

该文件同时负责页面路由、模型延迟加载、分类结果汇总、词云数据生成及前后端数据交互。

#### `db.py`

数据库访问模块，封装项目中的主要数据库操作，包括：

- 用户注册、登录与信息查询；
- 视频信息的新增、查询和删除；
- 评论分类结果的批量写入与读取；
- 用户自定义关键词的新增、查询和删除；
- 用户已处理视频数量 `v_cnt` 的统计与维护。

#### `back.sql`

数据库 `back` 的表结构文件，包含以下主要数据表：

- `user`：用户信息；
- `video`：视频信息；
- `comments`：评论及分类结果；
- `keyword`：用户自定义关键词。

首次运行项目前，需要先执行该 SQL 文件创建数据库和数据表，并确保数据库配置与 `db.py` 保持一致。

#### `预测.py`

模型推理与评论分类脚本，主要功能包括：

1. 加载本地 Qwen2.5 基础模型；
2. 根据评论板块加载对应的 LoRA 模型适配器；
3. 使用关键词规则优先识别部分评论；
4. 将其余评论批量输入大模型进行分类；
5. 输出类别 ID、中文标签及分类方式；
6. 将分类结果提供给 Flask 后端进行入库和展示。

系统目前将评论划分为以下五类：

| 类别 ID | 类别名称 |
| ---: | --- |
| 1 | 正常 |
| 2 | 争论 |
| 3 | 广告 |
| 4 | @某人 |
| 5 | 无意义 |

## 本地运行流程

1. 克隆项目并通过 Git LFS 下载模型文件；
2. 安装 Python、Node.js、数据库等运行环境；
3. 执行 `back.sql`，创建项目所需的数据表；
4. 修改 `db.py` 中的数据库连接配置；
5. 安装后端依赖并启动 Flask 服务；
6. 进入 `pinglun/`，安装前端依赖并启动 React；
7. 在浏览器中访问前端地址，注册或登录后使用评论分析功能。

## 注意事项

- 请确保基础模型和 LoRA 适配器的路径与代码配置一致；
- 请勿将数据库密码、Cookie、密钥等敏感信息直接提交到 GitHub；
- 建议通过环境变量或 `.env` 文件管理数据库连接信息；
- `.env`、Cookie、日志和本地缓存文件应加入 `.gitignore`；
- B站评论采集功能可能受到网络状态、Cookie 有效期和平台接口限制的影响；
- 使用评论数据时，请遵守相关平台规则及数据隐私要求。
